# PostgreSQL schema

`dataset_sources` catalogs provenance. `rainfall_observations` stores typed time, coordinates, millimetres, quality/source labels, a unique deterministic `observation_key`, and raw JSONB. `flood_hotspots` stores source attributes; `infrastructure_assets` stores typed assets and permits null coordinates for lines/polygons. Full EPSG:4326 geometry is retained in JSONB and GeoJSON when PostGIS is unavailable. `scenarios` owns `scenario_events` with cascading deletion. `data_quality_reports` stores structured checks. Loaders write `ingestion_runs` records with `running`, `completed`, or `failed` status, input/accepted/rejected counts, timestamps, and run details. Initialization uses additive `ALTER ... ADD COLUMN IF NOT EXISTS` migration for the observation key and creates indexes for time, source IDs, type, quality source, and scenario relationship. No PostGIS geometry query is provided.
