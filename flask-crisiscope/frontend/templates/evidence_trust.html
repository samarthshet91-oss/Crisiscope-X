Scenario Severity Index (SSI) Formulation
The composite SSI (0–100) mathematically combines four normalized hydrological and graph components: 
SSI = clamp(5, 100, 
  0.35 * (Rain / 320.0) +
  0.30 * (Disruptions / 4.0) +
  0.25 * (Isolated_Facilities / 3.0) +
  0.10 * (Soil_Saturation) -
  Mitigation_Credits
)
  • Mitigation Credits: Dewatering pumps (-7 pts), Drainage clearance (-5 pts), Preemptive rerouting (-4 pts).
  • Rational Limits: Never drops below baseline 5 or exceeds physical maximum 100.
Supervised Logistic Inundation Classifier
Probability of acute flooding is calculated via the standard logistic sigmoid: 
P(Inundation) = 1 / (1 + exp(-z))
z = β0 + β1*Rain_Intensity + β2*Cumulative_Rain 
    + β3*(Elevation - 850) + β4*Soil_Saturation 
    + β5*Drainage_Maintenance
  • Deterministic Coefficients: Trained via scikit-learn LogisticRegression with L2 regularization.
  • Explainability: Each feature's logit contribution is exposed directly in the UI.
